# RL0134

the comparison has no finite response bank

## What it means

comparison requires a finite response bank, and none was supplied

## What this means for the run

reward-lens exits 4: usage, configuration or input contract. Nothing was measured and no record was written. Many shells use 2 for a usage mistake; here 2 never means that.

## What usually causes it, and what resolves each

- supply the finite response bank for this comparison, then run: reward-lens compare <the earlier record> <the later record>
- to inspect the inputs a comparison uses before selecting responses: run: reward-lens describe
