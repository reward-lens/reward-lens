# RL0702

the adapter cannot prove it holds a capability the run needs

## What it means

the adapter the run was given does not prove the capability the measurement needs, so a measurement resting on it would not be honest

## What this means for the run

reward-lens exits 5: a capability, service or extra the run needed is unavailable, so the measurement that rests on it cannot be made.

## What usually causes it, and what resolves each

- to see what the adapter proved and what it only claims: run: reward-lens doctor
- run the measurements that do not need it and let the record carry the rest as absences: run: reward-lens audit .

## Offline

`reward-lens explain RL0702` prints this with the network off.
