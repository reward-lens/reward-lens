# RL0711

the provider could not complete the requested operation

## What it means

the provider the message names could not complete the requested operation, and the message says what happened

## What this means for the run

reward-lens exits 5: a capability, service or extra the run needed is unavailable, so the measurement that rests on it cannot be made.

## What usually causes it, and what resolves each

- check the provider credentials, network access and service status, then run: reward-lens doctor
- after the provider is available, run the same measurement again: run: reward-lens audit .

## Offline

`reward-lens explain RL0711` prints this with the network off.
