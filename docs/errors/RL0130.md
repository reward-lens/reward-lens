# RL0130

the run was interrupted

## What it means

the run stopped on an interrupt from the terminal, and the partial record was kept

## What this means for the run

reward-lens exits 130: the run was interrupted.

## What usually causes it, and what resolves each

- pick it up where it stopped: run: reward-lens audit --resume <the run id>
- to see what was written before the interrupt: run: reward-lens runs

## Offline

`reward-lens explain RL0130` prints this with the network off.
