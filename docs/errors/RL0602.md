# RL0602

an entry does not carry the evidence its kind calls for

## What it means

the entry the message names carries none of the evidence its kind requires

## What this means for the run

reward-lens exits 4: usage, configuration or input contract. Nothing was measured and no record was written. Many shells use 2 for a usage mistake; here 2 never means that.

## What usually causes it, and what resolves each

- to see what the record holds, run: reward-lens open <the record path>, which shows every entry that falls short
- add the evidence the kind calls for, or record the entry as an absence naming what is missing and why, which is what an honest gap looks like

## Offline

`reward-lens explain RL0602` prints this with the network off.
