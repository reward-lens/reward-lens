# RL0900

reward-lens failed internally

## What it means

reward-lens failed at the step the message names, which is a defect in reward-lens rather than in anything you gave it

## What this means for the run

reward-lens exits 7: reward-lens itself failed, or an integrity check did.

## What usually causes it, and what resolves each

- check that the install is intact and the environment is what you think: run: reward-lens doctor
- the run directory keeps the log and whatever was written before the failure: run: reward-lens runs

## Offline

`reward-lens explain RL0900` prints this with the network off.
