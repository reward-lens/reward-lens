# RL0310

the policy file cannot safely decide the record

## What it means

the policy file is malformed, inconsistent, or names evidence this build cannot safely evaluate

## What this means for the run

reward-lens exits 4: usage, configuration or input contract. Nothing was measured and no record was written. Many shells use 2 for a usage mistake; here 2 never means that.

## What usually causes it, and what resolves each

- correct the policy file and its declared evidence checks, then run: reward-lens audit . --policy <the policy file>
- keep the policy version immutable once it has decided a record; write a new version for a different set of checks

## Offline

`reward-lens explain RL0310` prints this with the network off.
