# RL0801

a decision only you can make is waiting, and there is no terminal to ask on

## What it means

the run stopped on a decision only you can make, which the message names, with no terminal to ask on

## What this means for the run

reward-lens exits 3: a decision only you can make is pending, and there was no terminal to ask on. The payload names the flag and the command to run.

## What usually causes it, and what resolves each

- make the decision on the command line and run it again: run: reward-lens audit . --policy <the policy to apply>
- in an automated job, set REWARD_LENS_NON_INTERACTIVE and pass every decision as a flag, so a run never waits on a terminal that is not there
