# RL0502

the seeker arm was asked for with no cap on what it may spend

## What it means

a paid seeker actor was requested without a money cap, so reward-lens refused before it could assemble a paid request

## What this means for the run

reward-lens exits 6: the money cap was reached. The record up to that point was written.

## What usually causes it, and what resolves each

- name the cap the paid arm may spend and run it again: run: reward-lens audit . --seeker api --max-budget-usd 0.50
- to run a local model at no cost instead: run: reward-lens audit . --seeker local
- to run the audit with no paid arm at all, leave the seeker off, which is the default
