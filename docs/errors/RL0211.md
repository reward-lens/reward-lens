# RL0211

the grader raises on input it will meet

## What it means

the grader raised on the case the finding names instead of returning a score, so that response has no measurement at all

## What this means for the run

Nothing stops. RL0211 is a finding the record carries, and a decision resting on the section it lands in stays unresolved until the finding is dealt with or accepted.

reward-lens exits 2: the decision asked for is unresolved, because the evidence is missing or inconclusive. Rejected and unresolved never collapse into each other.

## What usually causes it, and what resolves each

- catch the malformed case inside the grader and return a score for it, then measure again: run: reward-lens audit .
- if the raise is guarding a real defect, it belongs before scoring starts, not in the middle of a batch
- to see what the record holds, run: reward-lens open <the record path>, which carries the input that caused it
