# RL0131

the comparison replay inputs are not usable

## What it means

the comparison needs a closed run record and complete replay declarations, but one is missing, unreadable, incomplete, or incompatible with the requested comparison

## What this means for the run

reward-lens exits 4: usage, configuration or input contract. Nothing was measured and no record was written. Many shells use 2 for a usage mistake; here 2 never means that.

## What usually causes it, and what resolves each

- supply the closed run directory and the exact replay declarations for both versions, then run: reward-lens compare <the earlier record> <the later record>
- use the run record's declared groups, estimators, and recorded components; do not reconstruct any of them from row order or a version label
