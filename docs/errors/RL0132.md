# RL0132

the requested selection budget exceeds the finite response bank

## What it means

the requested selection budget is above half the smallest task-level candidate count in the finite response bank, which would exceed the declared selection limit

## What this means for the run

reward-lens exits 4: usage, configuration or input contract. Nothing was measured and no record was written. Many shells use 2 for a usage mistake; here 2 never means that.

## What usually causes it, and what resolves each

- choose a selection budget no greater than half the smallest task bank, then run: reward-lens compare <the earlier record> <the later record>
- to inspect the finite bank and its task-level candidate counts before selecting: run: reward-lens describe
