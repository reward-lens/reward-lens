# RL0402

the sandbox tier asked for is stronger than this machine holds

## What it means

the run required a stronger isolation tier than this machine holds, and the message names both of them

## What this means for the run

reward-lens exits 5: a capability, service or extra the run needed is unavailable, so the measurement that rests on it cannot be made.

## What usually causes it, and what resolves each

- to see what each tier needs and which one this machine holds: run: reward-lens doctor
- if the weaker tier is acceptable for this measurement, drop the requirement and let the record carry the tier that was used: run: reward-lens audit .
