# RL0229

the panel's own self-check refused a number it was about to report

## What it means

the soundness panel refused an output that would have reported a rate without a bounded interval or a mutation score without both denominators

## What this means for the run

RL0229 is an error, and exits 4, when the soundness panel is about to emit an invalid number. When an already-recorded measurement carries this code, it is a finding about that measurement and has no process exit.

reward-lens exits 4: usage, configuration or input contract. Nothing was measured and no record was written. Many shells use 2 for a usage mistake; here 2 never means that.

## What usually causes it, and what resolves each

- report the rate with a bounded interval and mutation scores with both denominators, or do not report the number at all: run: reward-lens audit .

## Offline

`reward-lens explain RL0229` prints this with the network off.
