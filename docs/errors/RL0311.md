# RL0311

the policy digest does not match the record

## What it means

the policy digest named by the record differs from the policy file used to decide it, so the decision cannot be reproduced from those two artifacts

## What this means for the run

reward-lens exits 4: usage, configuration or input contract. Nothing was measured and no record was written. Many shells use 2 for a usage mistake; here 2 never means that.

## What usually causes it, and what resolves each

- reload the exact policy version that produced the record, or make a new decision: run: reward-lens audit . --policy <the policy file>
- do not replace a policy file in place after it has decided a record; retain the recorded digest with the immutable policy bytes

## Offline

`reward-lens explain RL0311` prints this with the network off.
