# RL0301

the correctness claim is not qualified by an outcome check

## What it means

no outcome check stood behind the scores, so nothing here says a high score means correct work

## What this means for the run

Nothing stops. RL0301 is a state the record carries: it says what the measurement could not qualify, rather than that something went wrong.

reward-lens exits 2: the decision asked for is unresolved, because the evidence is missing or inconclusive. Rejected and unresolved never collapse into each other.

## What usually causes it, and what resolves each

- point the run at a protected test suite: run: reward-lens audit . --outcome ./outcome
- to see whether a suite is usable before you rely on it: run: reward-lens doctor --outcome ./outcome
- if there is no suite and there will not be one, the record says so as an absence, which is an honest answer rather than a missing one
