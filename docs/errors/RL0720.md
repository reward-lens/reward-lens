# RL0720

the requested tracker is unavailable

## What it means

the requested tracker cannot write this export because its required credential or offline destination is unavailable

## What this means for the run

reward-lens exits 5: a capability, service or extra the run needed is unavailable, so the measurement that rests on it cannot be made.

## What usually causes it, and what resolves each

- supply the named tracker credential or configure its offline destination, then run: reward-lens export <the record> --to <the tracker>
- use the file tracker for an offline export when no account-backed tracker is available

## Offline

`reward-lens explain RL0720` prints this with the network off.
