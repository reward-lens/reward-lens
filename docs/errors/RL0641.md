# RL0641

## What it means

the export scan found a credential-shaped value in the payload bytes, so no artifact was written from those unredacted bytes

## What this means for the run

reward-lens exits 4: usage, configuration or input contract. Nothing was measured and no record was written. Many shells use 2 for a usage mistake; here 2 never means that.

## What usually causes it, and what resolves each

- redact the reported value and write a new linked artifact, then run: reward-lens export <the record>
- keep the redacted artifact linked to the original export attempt so a reader can see what was removed without recovering the credential
