# RL0214

a reward function raised and the framework would score it 0.0

## What it means

a reward function raised the exception the message names while scoring a row, and the framework logs it and records 0.0 for that reward function

## What this means for the run

Nothing stops. RL0214 is a finding the record carries, and a decision resting on the section it lands in stays unresolved until the finding is dealt with or accepted.

reward-lens exits 2: the decision asked for is unresolved, because the evidence is missing or inconclusive. Rejected and unresolved never collapse into each other.

## What usually causes it, and what resolves each

- let the exception reach the caller, or catch it and return a score you chose on purpose, then measure again: run: reward-lens audit .
- a swallowed exception and an earned zero are the same number in the record, so a reward function that always raises reads as one that never rewards
- to see what the record holds, run: reward-lens open <the record path>, which names the exception and the row it was raised on
