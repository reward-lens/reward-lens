# RL0642

the record cites a rendering derived from itself

## What it means

the record names a rendered artifact derived from that same record, creating a self-reference that cannot serve as independent evidence

## What this means for the run

reward-lens exits 4: usage, configuration or input contract. Nothing was measured and no record was written. Many shells use 2 for a usage mistake; here 2 never means that.

## What usually causes it, and what resolves each

- remove the rendered-artifact reference and export the unchanged record again: run: reward-lens export <the record>
- keep the rendered artifact outside the record it renders, with a one-way link from the artifact to the saved record
