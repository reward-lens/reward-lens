# RL0704

the requested capability needs an extra that is not installed

## What it means

the capability the message names needs an extra that is not installed in this environment

## What this means for the run

reward-lens exits 5: a capability, service or extra the run needed is unavailable, so the measurement that rests on it cannot be made.

## What usually causes it, and what resolves each

- install the extra that carries it: run: pip install 'reward-lens[<the extra>]'
- to check the installed capabilities before running again: run: reward-lens doctor

## Offline

`reward-lens explain RL0704` prints this with the network off.
