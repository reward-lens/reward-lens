# RL0501

the money cap was reached

## What it means

the run reached the money cap it was given and stopped, and the record up to that point was written

## What this means for the run

reward-lens exits 6: the money cap was reached. The record up to that point was written.

## What usually causes it, and what resolves each

- raise the cap and continue where it stopped: run: reward-lens audit --resume <the run id> --max-budget-usd <a higher cap>
- to see what was already paid for and kept: run: reward-lens runs
- to find out what a run will cost before paying for it, ask for the plan rather than the run: run: reward-lens audit . --dry-run
