# RL0604

the record does not match the schema

## What it means

the record is not valid at the location the message names, and the message says what failed there

## What this means for the run

reward-lens exits 4: usage, configuration or input contract. Nothing was measured and no record was written. Many shells use 2 for a usage mistake; here 2 never means that.

## What usually causes it, and what resolves each

- to see what the record holds, run: reward-lens open <the record path>, which is where the failing path lives
- a record this build wrote should never fail this check: keep the file if one did, because the file is the evidence

## Offline

`reward-lens explain RL0604` prints this with the network off.
