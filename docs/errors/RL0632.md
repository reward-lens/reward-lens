# RL0632

the bundle signature is invalid

## What it means

the bundle signature does not verify for the stated signer and digest, so the received bytes cannot be accepted as the signed export

## What this means for the run

reward-lens exits 4: usage, configuration or input contract. Nothing was measured and no record was written. Many shells use 2 for a usage mistake; here 2 never means that.

## What usually causes it, and what resolves each

- restore the exported bytes or obtain a newly signed bundle, then run: reward-lens import <the bundle> --verify
- keep the signer and the digest reported by verification with the failed receipt; a signature identifies a signer but does not establish that an outcome claim is right

## Offline

`reward-lens explain RL0632` prints this with the network off.
