# RL0630

the record schema major is incompatible with this build

## What it means

the received record declares a schema major this build does not read, so its original bytes were preserved without interpreting the record as a current Assay

## What this means for the run

reward-lens exits 4: usage, configuration or input contract. Nothing was measured and no record was written. Many shells use 2 for a usage mistake; here 2 never means that.

## What usually causes it, and what resolves each

- use a reward-lens build that reads the declared schema major, or migrate the preserved source bytes: run: reward-lens import <the received record>
- keep the received bytes unchanged until a compatible reader or an explicit migration can account for every field

`reward-lens explain RL0630` prints this with the network off.
