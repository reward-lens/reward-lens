# RL0601

the record was written by a later version

## What it means

the record declares a schema major this build cannot read, and the file was left exactly as it was

## What this means for the run

reward-lens exits 4: usage, configuration or input contract. Nothing was measured and no record was written. Many shells use 2 for a usage mistake; here 2 never means that.

## What usually causes it, and what resolves each

- upgrade to a build that reads it: run: pip install --upgrade reward-lens
- to see which schema this build does read: run: reward-lens describe
- the file is not damaged and nothing was rewritten: an older build refusing a newer record is the contract working

`reward-lens explain RL0601` prints this with the network off.
