# RL0640

a projection needs a field the saved Assay does not carry

## What it means

the projection needs a named saved Assay field, but the saved Assay does not carry it

## What this means for the run

reward-lens exits 4: usage, configuration or input contract. Nothing was measured and no record was written. Many shells use 2 for a usage mistake; here 2 never means that.

## What usually causes it, and what resolves each

- run the measurement that retains the required projection evidence, then ask for the projection again: run: reward-lens audit .
- to see what the record holds, run: reward-lens open <the record path>

## Offline

`reward-lens explain RL0640` prints this with the network off.
