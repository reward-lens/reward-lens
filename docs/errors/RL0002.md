# RL0002

an identifier you supplied is not usable

## What it means

the value given for the field the message names is not a usable identifier, and the message says what makes it one reward-lens will not take

## What this means for the run

reward-lens exits 4: usage, configuration or input contract. Nothing was measured and no record was written. Many shells use 2 for a usage mistake; here 2 never means that.

## What usually causes it, and what resolves each

- quote the value in the shell and drop any control character, null byte or `..` segment, then run: reward-lens <the same command> again
- if the id came from an earlier run, the real ones are listed by: run: reward-lens runs
- to see what the record holds, run: reward-lens open <the record path>, which carries the ids it was written with

## Offline

`reward-lens explain RL0002` prints this with the network off.
